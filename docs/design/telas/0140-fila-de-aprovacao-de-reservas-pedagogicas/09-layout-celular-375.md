## Layout do celular (375 px)

Moldura de **375 px**, nome `[FAP - 0140] - Fila de aprovação de reservas pedagógicas (Stitch → Figma) / Mobile`.

- **Cabeçalho móvel** de 64 px: botão de menu (abre a gaveta do card 0101), logo e sino.
- **Principal** em coluna única, 16 px de respiro e 16 px entre blocos.
- Botões de ação ocupam a largura toda; o primário fica no fim do bloco.
- Tabelas viram **lista de cartões** (uma pessoa ou item por cartão, com badge de status).
- Modais viram folha de baixo para cima com largura total.

Ordem dos blocos no celular:

1. Lista de pendentes
2. Ações
3. Painel de detalhe
4. Chips
