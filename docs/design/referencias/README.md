# Imagens de referência das telas

Wireframes de **ideia** (não são o design final) para cada card de tela do fluxo
(`../fluxo-de-telas.md`). Servem para quem desenha no Stitch entender a estrutura
esperada: menu, cabeçalho, tabelas, formulários, modais e estados principais.

O visual final segue sempre `../stitch/DESIGN.md`. Cada imagem se chama
`<número do card>-referencia.png` e fica anexada ao card correspondente no Trello.
